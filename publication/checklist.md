# Publication checklist

## Before sharing

- [ ] Verify the manuscript's lower bound, construction, conjecture correspondence, and claimed covering corollaries. Resolve audit findings.
- [ ] Record qualified novelty language and the original sources for every reused result and construction.
- [ ] Check that the PDF and Lean evidence match the exact release candidate. Keep the axiom audit and clean build record with it.
- [ ] Have the proposed human author review the proof, contributions, citations, and disclosures. Confirm authorship eligibility, responsibility, and consent for the target before using the byline externally.
- [ ] Confirm any displayed name, affiliation status, correspondence email, ORCID, funding, and competing interests. Enter only verified information.
- [ ] Confirm rights to ship all files, review the manuscript license and MIT scope, and scan the full public history and release payload for private or third-party material.
- [ ] Obtain approval for the exact recipients and reviewer packet before sending a private expert-review request.

## Release and archive

- [ ] Verify that the source bundle builds the same paper from a clean directory. Check references and inspect the PDF.
- [ ] Unpack the release and check for Lean and Mathlib pins, verification instructions, certificates, license text, and attribution. Verify hashes against the intended payload.
- [ ] Approve the final repository and public history before pushing or publishing the `v1.0.0` release.
- [ ] Approve the Zenodo software deposit. Review the exact file and AI description in the draft [metadata](zenodo.json). Use a single deposit route.
- [ ] Verify the record and version DOI after authorized publication. Add confirmed URLs and identifiers to the repository and manuscript metadata.

## Preprint and journal

- [ ] Check the target journal's preprint and archiving terms before selecting an arXiv license.
- [ ] Check endorsement status in `math.CO` and obtain approval before inviting an eligible endorser, if required.
- [ ] Verify the arXiv-compiled PDF, metadata, license, and reproducibility link. Obtain approval before posting.
- [ ] Prepare DCC editable sources and PDF, an artifact availability statement, declarations, and the final cover letter. Check the submission preview and obtain approval before submitting.
- [ ] Submit to one journal at a time. Obtain separate approval for any paid publication option.
