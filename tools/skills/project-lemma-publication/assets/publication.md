# Publication record

Record the problem ID, precise claim, version, and last reconciliation date here. For each entry give the checked commit or input hash, date, outcome and durable source. Mark unrun checks as pending.

| Question | Assessment | Evidence or limitation |
| --- | --- | --- |
| Mathematical correctness | Pending proof review | |
| Formal verification and scope | Pending assessment | |
| Historical novelty | Pending source search | |
| Independent peer review | No review recorded | |

## Verification

Record signed-off hypotheses and exclusions, adversarial objections and resolutions, certificate replay, formal contracts and axioms, dependency pins, clean-build commands and discrepancies between proof and formal statement. Identify the reviewer as human or AI and note reused dependency objects.

## Publication

Record the provider, commit, tag, date, public manuscript URL, source archive, SHA-256 values, job URLs and anonymous download check. Include the recommended citation and any verified DOI or registry ID.

Track authorization, intent, submission, acknowledgment and explicit acceptance separately. Keep private support ticket links, personal email addresses, credentials and correspondence permissions out of public records. Record unresolved priority sources and operational lessons.
